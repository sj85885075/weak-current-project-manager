# 弱电项目管理小工具

Windows 本地运行的弱电工程项目管理工具，包含项目总览、人员、子系统工作包、进度、材料与 CAD 点位设计。

## 功能

- CAD 底图上的设备布置、移动、旋转、翻转及施工状态登记。
- 网线、光缆和桥架绘制，端点连接、最近设备自动连接与平面长度统计。
- 设备安装、调试和线路布放统计，项目台账联动。
- 工作包、施工流程、材料管理与交付资料。

## 运行与数据

当前上传内容是源码快照，不含账号凭据、现场项目台账、CAD 图纸、运行环境和历史备份。
本工具依赖配套项目文件体系，`server.py` 默认以程序目录的上一级作为项目数据根目录；单独下载本仓库不包含可直接运行的业务数据。
使用 Python 运行 `python server.py`，默认访问 `http://127.0.0.1:8765`。
Python 外部依赖需按所使用模块安装；CAD 的 DWG/DXF 原生导入另需本机 AutoCAD 及其 Core Console。
首次使用需在本机设置登录账号。

原图设备编号可能由邻近 CAD 文字自动匹配，属于待核对标注；新增设备留空编号时由系统生成流水号。施工前应核对正式点位编号。
