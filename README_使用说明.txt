BG 项目管理系统集成小工具 · 使用说明（双项目版）
============================================

本工具已内置两个相互独立项目，共用同一界面，数据互不干扰：
  [1] BG 弱电改造项目 —— 印尼BG工厂新建数据中心及办公区弱电改造
  [2] 泰坦IDC数据中心光缆施工工程 —— 72芯集束光缆15天施工

一、如何启动
1. 双击本文件夹内的「启动工具.bat」（推荐）
2. 浏览器自动打开 http://localhost:8765

也可以直接双击「bg_tool_server.exe」——服务在后台静默运行，
2 秒后自动打开浏览器，不出现黑色窗口。

停止工具：双击「停止工具.bat」（或在任务管理器结束 bg_tool_server.exe）

（无需安装 Python：工具已内置独立服务组件 bg_tool_server.exe；
  再次双击「启动工具.bat」会直接打开界面，不会重复启动服务）

二、项目切换
1. 界面右上角「当前项目」下拉框可切换 BG / 泰坦IDC 两个项目
2. 切换后整个界面（总览KPI、子系统、人员、问题、图表）自动切换为该项目数据
3. 两个项目各自独立的 Excel 数据文件（见下方目录），互不影响

三、功能说明（两个项目功能一致）
1. 项目总览
   - 项目 KPI（BG：合同金额/工期/到场/子系统进度；泰坦：项目范围/15施工日/到场/计划总进度）
   - 各子系统状态灯（LED：红=问题/未开始、黄=流程中、蓝=施工调试、绿=完成），点击卡片进入填报
   - 图形化进度分析（ECharts，随填报数据实时联动）：
     ① 项目总进度仪表（综合完成率，按各子系统完成率平均）
     ② 子系统状态分布饼图
     ③ 各子系统完成率横向条形图
     ④ 施工进度甘特图（BG 横轴 D+X 合同生效后自然日；泰坦横轴 T+X 开工后施工日）
     ⑤ 里程碑时间轴（BG M1~M12 / 泰坦 M1~M4）
     ⑥ 到场人数趋势（BG 近31天 / 泰坦 15 施工日）
     ⑦ 泰坦项目专属：15天每日计划工程量六分项堆叠柱 + 累计完成率折线
   - 里程碑列表、当前关注事项（风险/问题/工期口径）

2. 人员管理（同步 29 号文件）
   - 选择日期，填写当天到场人员：姓名 / 职位 / 来源(中方·当地) / 班组 / 工作类型 / 区域 / 工作内容 / 工时 / 备注
   - 顶部实时统计：到场总人数、中方、当地、施工/安装、调试、验收、管理人数
   - 「复制前一天」可把昨天的人员行复制到今天（姓名需重填）
   - 保存后：29 号《每日到场汇总》自动汇总人数，《人员明细》按日期归档
   - 泰坦项目班组按 6 个施工班组划分（分拣预打标/7F布线/9F布线/ODF端接/测试质检/后勤）

3. 子系统进度（同步 30/31/32 号文件）
   - 先点上方子系统按钮切换（BG 10 个子系统；泰坦 6 个分项）
   - 每个子系统 4 块内容：
     (1) 概览：当前状态下拉、负责人、今日工作内容
         今日/累计完成由详细工程量自动汇总，无需手填
     (2) 详细工程量（32 号表）：只填「今日完成」，保存后自动累加至累计，
         并自动生成当日每日计量流水（30 号表）
     (3) 施工步骤（32 号表）：如支架安装→设备安装→调试→验收；
         每步可选 未开始/施工中/已完成/暂停/不适用，填完成日期，
         未完成/未通过原因写在备注栏
     (4) 验收记录（32 号表）：内部验收 / 试运行 / 终验收（泰坦为 M1~M4 里程碑验收+内部验收+终验收），
         选 未开始/已通过/未通过/不适用，填验收日期、验收人、结论；
         未通过时手工录入原因与整改完成日期
   - 今日工作内容写入 31 号备注列；31 号今日/累计由 32 号明细自动汇总

4. 问题与待办
   - 新增问题（描述/优先级 P0~P3/责任人/计划解决日期）→ 保存后追加到 05 号文件《问题清单》
     （BG 自动编号 ISSUE-xxx；泰坦自动编号 TISSUE-xxx 续接预置的 7 项甲方待确认）
   - 展示当前问题清单与待办基线（BG 10 项 / 泰坦 7 项）

5. 数据管理
   - 保存并同步 Excel：一次写入当前项目的 29/30/31/32/05 五个文件（保留原有格式）
   - 导出 JSON 备份 / 导入 JSON 恢复 / 从 Excel 重新载入

四、同步的 Excel 文件（两个项目各自独立）
BG 项目（位于上一级目录）：
- 29_项目人员管理表.xlsx —— 每日到场汇总 + 人员明细 + 班组人力计划
- 30_项目进度工程量跟踪表.xlsx —— 工程量总览 + 每日计量（明细自动追加流水）
- 31_子系统状态总览表.xlsx —— 子系统状态/负责人/更新时间（今日/累计由明细汇总）
- 32_子系统施工步骤与明细表.xlsx —— 详细工程量 + 施工步骤 + 验收记录
- 05_项目问题及待办事项.xlsx —— 问题清单（追加）

泰坦IDC项目（位于「泰坦IDC\」子目录，与 BG 完全独立）：
- 29_项目人员管理表.xlsx —— 每日到场汇总 + 人员明细 + 班组人力计划（15 施工日 2026-09-10 ~ 09-24）
- 30_项目进度工程量跟踪表.xlsx —— 工程量总览 + 每日计量 + 每日计划（六分项 15 天计划/累计/人员）
- 31_子系统状态总览表.xlsx —— 6 个分项状态
- 32_子系统施工步骤与明细表.xlsx —— 35 个施工步骤 + 14 个详细工程量 + 36 行验收记录（M1~M4/内部/终验）
- 05_项目问题及待办事项.xlsx —— 问题清单（预置 TISSUE-001~007 甲方待确认）

五、数据规则
- 所有输入为项目现场真实填报；未确认项填【待确认】或留空，工具不编造数据
- 施工步骤与明细项预设依据：甲方技术协议 / 施工计划 / 工程量清单 / 图纸 / 工程经验；
  计划总量未核定的标【待确认】，确认后在 Excel 中调整
- 泰坦项目总工程量 7216 单位（分拣1152条 / 7F布线576条 / 9F布线576条 / ODF304个 / 端接2304端 / 测试2304条）
- 建议每日下班前 10 分钟填报当日人员与工程量，周例会使用 31/32 号表复盘

六、常见问题
- 页面打不开：确认已运行「启动工具.bat」且无黑框弹错；若提示"端口 8765 被占用"，说明工具已在运行，直接打开 http://localhost:8765
- 首次双击后浏览器若显示"无法访问此网站"，等待 3~5 秒后点击"重新加载"或手动刷新
- 浏览器版本：建议 Chrome / Edge 最新版


【v2.2 新增 工程审计 + 施工进度检查】
1. 工程审计（两个项目均有）：导航新增「工程审计」，支持 甲方检查/内部检查/内部验收/终验收 四类检查，
   按日期登记问题（问题描述、现场图片多选上传、是否已处理、处理时间、处理说明、登记人）。
   图片保存到「工程审计\检查日期\」文件夹（BG 在体系根目录下，泰坦在 泰坦IDC\工程审计\ 下），
   登记记录写入 33_工程审计登记表.xlsx。
2. 施工进度检查（仅泰坦）：导航新增「进度检查」，对照《72芯集束光缆15天详细施工进度计划表》，
   逐日展示 计划当日量/实际当日量/当日差额/累计计划/累计实际/累计差额/完成率/判定状态（达标/预警/落后），
   并给出总体进度检查卡与「每日计划 vs 实际」图表。实际量取自 30 号每日计量流水（子系统页填报明细保存后自动重算），
   数据写入 34_施工进度检查表.xlsx。
3. 判定规则：累计实际 >= 计划*98% 达标(绿)；>=90% 预警(黄)；<90% 落后(红)。

【v2.3 新增 每日记录与测试归档】
1. 新增「每日记录」页面，统一登记施工、测试、材料、安全和协调事项，数据独立同步至 35_项目每日记录表.xlsx。
2. 泰坦IDC项目已预置 2026-09-11 的「288芯 OTDR 光纤测试」：142 芯/链路、全部通过、OS2 单模、两处 ODF 标识及关联测试报告。
3. 请先运行「停止工具.bat」停止旧版服务，再双击「启动新版工具.bat」启动新版界面。

【v2.4 新增 项目管理体系核心库】
1. 新增「项目管理体系」页面：包含项目基础参数、五大过程组、十大知识领域、管理过程库、WBS、计划实际对比与修改历史。
2. 每个项目目录各自保存「项目管理核心数据.db」（SQLite），只存新增的治理数据；原有 29/30/31/32/34/35 号 Excel 台账不改结构、不覆盖历史记录。
3. 完成项目参数后点击「按参数生成 WBS」。系统从 30 号表读取已有各子系统工程量作为初始计划量；生成后可逐项录入每日实际量，自动计算累计量、剩余量、计划完成率、实际完成率及进度偏差。
4. 新版本使用 server.py 提供接口，请通过「启动新版工具.bat」运行；如果旧版服务已占用 8765 端口，先运行「停止工具.bat」再启动新版。


2026-09-15 计划参数维护
在“项目管理体系”→“WBS 与计划实际对比”点击“修改计划”，可修改任务名称、单位、计划起止、自然日工期和计划完成量。修改工期需先指定开始日期。清空计划参数后点击保存；删除任务需确认，实际流水和变更历史保留，该任务退出 WBS 统计。
保存后，WBS 指标及全局概览、进度检查页的“WBS 计划与实际统计”自动更新。计划完成率按任务日期和计划量加权，未设置任务日期时使用项目计划日期。原 Excel 现场统计仍按台账口径展示。
本次功能需运行 server.py 新版服务；关闭当前 Python 服务后双击“启动新版工具.bat”，再刷新页面。旧版 EXE 未包含新增接口。


【v2.5 新增 标准WBS与工作包导入】
1. “项目管理体系”页面新增“下载WBS模板”和“导入WBS”，支持 XLSX/CSV。
2. 导入采用两阶段处理：先校验预览，再由用户确认写入；同一 WBS 编码执行合并更新，任务ID、实际完成量和历史流水保留。
3. 支持“汇总节点 / 工作包 / 活动 / 里程碑”四种类型，以及上级WBS、责任人、计划日期、计划量、单位、权重、前置WBS、交付物和验收标准。
4. 汇总节点由下级叶子任务自动汇总，不能直接录入实际完成量，避免父子层级重复计量。
5. 项目统计按叶子工作包计算，并按单位分别显示计划量和实际量，避免将“条、台、端、米”等不同单位直接相加。
6. WBS列表支持层级缩进、搜索和汇总节点识别；计划编辑增加责任、前置关系、交付物及验收标准。
7. 导入会检查编码重复、上级不存在、层级循环、日期错误、非法数量以及不存在的前置任务。
8. 新功能由 server.py 新版服务提供，请使用“启动新版工具.bat”。旧版 bg_tool_server.exe 不包含本功能。
9. 一级WBS施工分项与“子系统进度”的主计量项直接同步：计划量、累计实际、单位、负责人、状态及工期以子系统台账为唯一数据源；WBS页面不再重复填报，并可直接进入对应子系统。
